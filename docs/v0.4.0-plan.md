# Gooey 0.4.0 Plan

## Status

In progress on `integration/v0.4.0`. This document is the source of truth for the 0.4.0
simplification. Update the workstream table when work lands.

## Goal

Reduce Gooey to a small kernel of building blocks that humans and coding agents can learn
quickly and use without silent mistakes. Everything else (components, charts, animation
helpers, accessibility presets) becomes library code written only against the kernel.

The test for completeness: no component may reach into `Window`. A component that needs
`getGooey()` means the kernel is missing a block.

## Where 0.3.1 stands

The main pipeline is sound and fast: tree → layout → render commands → scene → GPU. Layout
costs about 40–70 ns per node. The weight comes from two sources:

- **Side channels around the pipeline.** Text inputs, text areas, code editors, scrollbars,
  and canvas leave the render-command stream through `pending_*` queues in `ui.Builder` and
  are painted after layout in `runtime/frame.zig`. Canvas uses an O(commands × canvases)
  scan with a 256-order reservation. Text widgets are special-cased again in
  `runtime/input.zig`.
- **Several spellings of each concept.**
  - About 11 identity schemes (layout `u32` hash, focus `u64` hash, positional auto ids,
    animation keys, entity ids, and more).
  - 7 state containers (root state, entities, element states, animation pools, change
    tracker, globals, app-owned list states).
  - 3 handler encodings behind 9 constructors.
  - 4 entry points (`run`, `App`, `WebApp`, `MultiWindowApp`).
  - 9 scene primitive kinds with about 30 `insert*` variants.
  - 3 renderers with no shared contract.

Known defects that motivate the work:

- Vulkan draws 5 of 9 primitive kinds; path, polyline, and point clouds are TODO stubs.
- Metal clears frames that contain only paths (`metal/renderer.zig` early return).
- `element_states` never evicts, so it fills to 4096 entries and then returns `null`.
- Many silent failures: non-renderable children are dropped, a handler with the wrong
  state type is a runtime no-op, unknown `App` config fields are ignored, `ui.when` is
  eager, default text colour ignores the theme.
- Runtime allocation after initialization in dispatch, focus, entities, and animation,
  which breaks CLAUDE.md §2.

dependencies on three platforms: hand-written Vulkan, Wayland, FreeType, CoreText, and
Objective-C bindings, plus per-platform windowing, IME, clipboard, dialogs, text, and
accessibility. Going below it requires product cuts (see Open decisions).

## Strategy

Rewrite the middle on a fresh `kernel/` tree inside this repository. Harvest the leaves that
are independent of the middle. Port the leaves that are coupled to it.

- **Harvest, about 45k lines:** layout, accessibility, SVG, image, text, and platform
  windowing and input. They depend only on `core`, `input/events`, or `layout`. The id
  change still reaches `LayoutId` and the accessibility tree.
- **Port, about 17k lines:** the Metal, Vulkan, and web renderers, which are built on the
  9-kind Scene and `BatchIterator`.
- **Port, about 10k lines:** the widget engines. Text engines paint into `*Scene` and
  implement the `context/focus` Focusable; lists and the table take `*Builder`.
- **Rewrite, about 38k lines:** the middle. Every kernel block crosses all of it.

A full restart would discard IME, Wayland, AppKit lifetime fixes, shaping, screen-reader
bridges, and the text-editing engines, none of which are the problem. An in-place refactor
was tried in the PR 5 → 11b series and left the duplicate spellings in place, because each
kernel block requires the old and new forms to coexist across the whole middle.

## Kernel

Nine blocks. This revision folds in the oracle review of the first draft.

1. **Element.** `box`, `text`, and `paint`. One container style covers row and column,
   sizing, appearance, events, accessibility annotation, and `key`. `text` uses theme tokens
   by default. `paint` is canvas with a typed data pointer and box sizing.
2. **ElementId.** One `u64`, scoped to the parent. Explicit keys mix with the parent id. Auto
   ids are only for stateless nodes. A duplicate key under one parent fails fast in Debug.
   Layout, hit testing, focus, accessibility, retained state, and animation all key on it.
3. **Retained store.** `cx.retain(T, id, lifetime)` returns a generation-checked handle, not a
   pointer. Three lifetimes:
   - `.frame`: swept when untouched, after a bounded delay so exit animations finish.
   - `.scope`: alive while an ancestor is touched or marked keep-alive. Hidden tabs keep
     undo history and scroll position.
   - `.owned`: released explicitly. List and table states use this.

   Slabs are sized by size class from the budget, so the budget does not list app types.
   This replaces `element_states`, `AnimationStore`, `ChangeTracker`, and the `pending_*`
   queues.
4. **Handler.** One type, built with `cx.on(State.method)` or `cx.on(arg, State.method)`. A
   `*Window` parameter is detected from the signature. A wrong state type is a compile
   error. Every event field (`on_click`, `on_change`, `on_select`, ...) takes this type.
5. **Runtime.** One bounded event queue and one tick driver for every platform:
   drain → build → layout → emit paint and hit records → pack → draw → swap.
   - The tick runs on the main thread. The macOS display link only signals it, which
     removes `render_mutex`.
   - Synchronous platform questions (IME rect and range, hit test, whether the keymap
     claims a key) go through a read-only query interface over `rendered_frame` that cannot
     mutate state or re-enter the framework.
   - Timers and async completions arrive through the queue.
   - One capture and bubble router for every event kind, including focus order, key
     contexts, and a drag payload slot. Text widgets become ordinary focusables.
   - Queue overflow coalesces pointer moves and scroll deltas, and fails fast with the queue
     name for anything else.
6. **Layers.** Paint fragments and hit records share one ordering, so floating content paints
   and receives input in the same order. See `docs/layout-layering-design.md`.
7. **App store.** Entities, keymap, theme, and atlases shared across windows. Typed fields,
   not a generic globals map.
8. **Scene.** Four kinds in one draw-ordered stream:
   - `Quad`: SDF fill, border, and blur. A shadow is a blurred quad.
   - `Sprite`: atlas id, UV, tint, and mode, with explicit fields for two-colour SVG, image
     corner radii, grayscale, opacity, and colour emoji.
   - `Mesh`: a range in one mesh pool with a topology (`triangles`, `strip_expanded`,
     `point_instanced`) and a solid or gradient fill. Polylines and point clouds stay
     GPU-expanded.
   - `Clip`: push and pop state.
9. **Backend.** `Platform`, a `Renderer` contract (`initInPlace`, `uploadAtlas`,
   `draw(packed, viewport, clear)`, `resize`, `deinit`) with capability-gated post-process
   passes, a `NullRenderer` on `src/testing/test_backend.zig`, and three services: text,
   image decode, and SVG rasterization. Liquid glass stays in the platform window.

**Budget.** `ResourceLimits` from PR #77 grows from `scene` to also cover layout, dispatch
records, retained slabs, the event queue, atlases, component depth, and maximum framebuffer
size.

**Pack stage.** The kernel emits paint records, and the pack stage turns them into renderer
input. Until the four-kind Scene lands, pack targets today's Scene so the existing renderers
keep working. This is a permanent boundary, not a temporary adapter: only its output type
changes later.

## CLAUDE.md requirements for the contract

The kernel contract must settle these before implementation:

1. **§6 recursion.** Component rendering recurses through `cx.render`. Add
   `component_depth_max` to `ResourceLimits` (default 64, ceiling 128), track depth in
   `cx.render`, and fail fast past it. Approved as the one structurally bounded exception
   to §6.
2. **§8 direct reaction.** Synchronous platform queries are read-only and documented at the
   call site. All state changes go through the queue.
3. **§2 static allocation.** Text engines use fixed buffers sized from the budget (bytes per
   input, undo depth). `Renderer.resize` and atlas growth use storage reserved for the
   budget's maximum framebuffer and atlas sizes.
4. **§7 performance sketch.** Bytes per retained slab, records per frame, event queue depth
   and drain rate, pack bandwidth per Mesh topology, and memory per window at `.standard`.
5. **§14 WASM stack.** Large kernel structs use in-place `noinline` initializers and
   comptime size assertions.
6. **§3 assertions.** Each kernel function states its preconditions and postconditions in the
   contract.
7. **§6 dynamic dispatch.** A `Handler` is a function pointer. The number of calls per tick is
   bounded by the number of drained events.
8. **§26 tooling.** Golden capture and the old-path import ban are Zig programs.

## Verification

Hardware: Linux orbs render with Mesa lavapipe (software Vulkan). Real-GPU checks run on Amp
runners: macOS/Metal on a Mac runner, and Linux/Vulkan on the `duane-SER9` runner (AMD RADV).
Renderer PRs are verified on real hardware before merge.

- **Primary oracle:** golden files of paint records, hit records, and the accessibility tree,
  produced from scripted input traces on `TestBackend` with the `NullRenderer`. Capture them
  from `main` before porting each feature cluster.
- **Simulation:** grow the trace harness into a seeded simulator that generates random event
  sequences and checks invariants (focus valid, no stale handle dereferenced, deterministic
  records).
- **Pixels:** a small screenshot set with a tolerance and an allowlist of known `main`
  rendering bugs. Pixel diffs alone do not cover input, IME, focus, or accessibility.

## Phases

- **A.** Cut examples and history comments (policies below). Exit: builds, tests, and fmt
  pass on Linux and macOS CI.
- **0.** Merge PR #77 (`ResourceLimits`, Metal instanced quads, Vulkan fail-fast, macOS
  teardown fix) to `main`, then into this branch. Do not extend `SceneLimits` further; that
  Scene code is replaced in phase 5. The one exception is aggregate per-frame geometry budgets
  (path vertices, polyline points, points), which the mesh pool needs.
- **1.** In place: fail-loudly compile errors, one `Handler` type, Vulkan path, polyline, and
  point pipelines, and the Metal path-only frame fix. Exit: the old silent mistakes become
  compile errors or panics that name the failure.
- **2.** Kernel contract: Zig signatures for the nine blocks, the requirements above,
  `NullRenderer` and record dumps on `TestBackend`, and goldens captured from `main`. Exit:
  contract reviewed and approved.
- **3.** Milestone 1: counter and todo, including a TextInput with IME composition, on
  `TestBackend` and macOS through the pack stage. Exit:
  - No allocation after init, checked by a lifecycle guard.
  - Goldens are stable.
  - The IME rect query is answered synchronously.
  - A file dialog opened from a handler runs on the main thread.
- **4.** Port the text engines (records, focusables, fixed buffers) and list states
  (`.owned`). Port components and examples by feature cluster. Move Linux and web onto the
  shared tick. Exit: each cluster matches its goldens.
- **5.** Four-kind Scene and Renderer contract, one backend at a time, behind the pack stage.
  Exit: the pixel set matches within tolerance.
- **6.** Delete the old middle one subsystem at a time as each loses its last consumer. A CI
  check bans new imports of old paths. Exit: the old middle is gone.

### History comments

Remove comments that narrate how the code changed rather than why it is correct now:

- PR references such as `PR 7b.3 —`, `(PR 8.4)`, `pre-PR-9`, `post-7c.3c`.
- Past-state narration such as "was X", "used to", "historically", "previously", "earlier
  drafts", "renamed from", "retired".
- Changelog blocks inside source files.

Keep the reasoning inside such comments and rewrite it in the present tense as a rationale
or invariant. For example, a note that a per-backend enum once had mismatched tag values
becomes: "One canonical enum shared by every backend, so tag values cannot disagree."

Comment-only changes. A scratch check must show that each file is identical before and after
once comments are stripped. `docs/` keeps its history sections.

## Noticed during phase A and PR #77 verification

Fix in phase 1 unless a later phase deletes the code first:

- `PR 7b`-style references remain inside `@compileError` strings in
  `src/image/asset_cache.zig` and `src/context/owned_flag_audit.zig`.
- `src/text/text_debug.zig` has no users and no tests since `text_debug_example` was dropped.
- `charts/README.md` Quick Start calls `chart.bindRender()`, which does not exist.
- `src/widgets/uniform_list.zig` says `Builder` is imported lazily; it is imported at the top.
- A TODO in `charts/src/charts/scatter_chart.zig` says the batched path is off; the code uses it.
- The Metal path-only early return (`metal/renderer.zig`) is latent: real apps always emit a
  transparent quad per element, so it fires only once transparent quads are culled. Fix it in
  phase 1 before any quad culling lands.
- `virtual_list_example` panics on its first frame: `Color.rgba(0, 122, 255, 1.0)` at
  `src/examples/virtual_list_example.zig:240` passes 0–255 values where 0–1 is asserted.
- Mac runners have no GitHub credentials, so runner threads hand commits back as git bundles
  for an orb thread to push.
- Metal baselines for phase 4 are on the Mac runner under
  `~/.amp/in/artifacts/gooey-baselines/738bf06/` (23 examples). spaceship and code-editor
  animate; crop the top 64 px (title bar) before diffing.
- Metal's path, polyline, and point pipelines grow GPU buffers at runtime
  (`growVertexBuffer`, `growIndexBuffer`), which breaks CLAUDE.md §2. Move them onto the
  aggregate geometry budget added for Vulkan in PR #89.
- Vulkan synchronization validation reports `SYNC-HAZARD-WRITE-AFTER-WRITE` at
  `vkCmdBeginRenderPass`: the render pass lacks an external subpass dependency. It predates
  PR #89 (same counts on the baseline). The instance also requests Vulkan 1.0, which disables
  GPU-assisted validation.
- The macOS benchmark gate fails on PRs that do not touch benchmarked code (PR #84 changed
  only examples, yet triangulator benchmarks reported +40% to +580%). The gate is noisy on
  shared runners and needs a tolerance or repeated runs before it can block merges.

## Decided

- **PR #77:** merged to `main` and into this branch (phase 0). Verified on macOS/Metal:
  1344/1344 tests pass, six examples are pixel-identical to `main`, and it fixes a segfault
  on `main` when a window is closed from the title bar.
- **§6 exception:** bounded component recursion with `component_depth_max`, default 64,
  ceiling 128.
- **`Cx`:** one untyped `Cx`. Handler and `cx.state` type checks run in Debug and ReleaseSafe
  and panic on the first frame; ReleaseFast and ReleaseSmall compile them out.
